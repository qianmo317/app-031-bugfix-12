# 定制家具板材开料优化（Furniture Cutting Optimizer）

把一批定制柜体零件清单丢进去，自动算出要买几张板、每张板怎么摆、按什么顺序下锯、连封边米数和五金胶量一起给出来。
纯前端 Vue 3 + Typecript + Vite 单页应用，**无后端、无外部 CDN、断网可用**，数据仅保存在浏览器 localStorage。

## 技术栈与约束

- Vue 3 `<script setup>` 单文件组件 + TypeScript（状态仅用 ref/reactive/computed/watch，无 Pinia/Vuex）
- Vite 5 构建；vue-router 4；手写 CSS（无 UI 组件库、无图表/游戏/物理库）
- 排样与刀路全部本地实时计算（≤1000 零件），不使用 worker/Service Worker

## 核心能力（对应规格书 §4/§5）

1. **板材库**：2440×1220 / 2745×1220 / 1830×915 等常用规格、厚度、材质、单价、库存张数；锯路 kerf（默认 3.2mm）、四周修边（5~10mm）可配。新项目默认带 **18mm 厚板 + 25mm 常用厚板 + 9mm 背板**三种；同名称/材质/长/宽/厚的板只允许一条（禁重复添加、禁改成重复规格），库里至少保留一种板（最后一种不许删）。长宽厚填 0 或负数、修边量比板子还大都会被当场拒绝。
2. **删板/改板与零件引用同源**：删除或改小某种板的厚度前，会先点名仍指定它的零件并要求确认。删板走「清除这些零件的指定、回到自动挑板」一条路——当场能删，代价是这些件对板厚/材质的要求丢失，可能被排到厚度/材质对不上的板上（另一条「拦住不许删、先改零件」保住用料要求但当下删不动，未采用）。库/零件任一改动，旧排样结果与下料单立即按输入签名作废，重排前不可能打出含已删板行的领料单。
3. **guillotine 贯通排样**：递归二分布局，只产生推台锯/电子锯可直接加工的矩形分割，禁止把小块塞进缝里；多板种混排（柜体板 + 背板）、按柜体批次分组开料。
4. **纹理硬约束**：竖纹/横纹件一律不旋转（`rotated=false`），无纹理件自动选朝向；放不下时明确提示「因纹理要求（不可旋转），现有板材排不下」，绝不偷转。录入提醒按纹理方向分别比可用板幅：竖纹比「零件长 vs 板长、零件宽 vs 板宽」，横纹比「零件宽 vs 板长、零件长 vs 板宽」——横纹件宽超可用板长同样逐方向点名。
5. **锯路/修边精确扣除**：零件间净距与四周边距均 ≥ kerf/trim；修边在板的两侧各扣一份，可用幅面 = 板长/宽 − 2×修边；利用率分母=板面积，分子=零件净面积（不含锯路、不含锯缝两侧余量）。
6. **裁切步骤动画与打印**：输出每一刀的轴向、坐标、贯通区间；同向刀连续排程（减少推台翻转），同规格板修边刀按叠切合并计数；页面可逐步播放（灰线→红线→已切），并支持 A4 打印贴在机器旁。
7. **材料统计**：张数、利用率、封边见光/非见光分列（按零件实际边长逐边累加）、三合一/木榫/螺丝/封边胶估算、板材成本，以及「比随手排省 N 张、约 X 元」；领料/成本表按板种 **boardId** 汇总，与板材库、排样实际挑中的板是同一份结论。
8. **余料登记与闭环**：每张板剩余矩形按面积降序记录，两边 ≥300mm 标为可用；一键登记后，在新项目零件清单页勾选即以「小板材」身份**优先参与下一轮排样**，用掉自动标记已用。
9. **手工微调**：排样图上可拖动零件到余料矩形或与同尺寸零件交换；每次松手立即做 guillotine 合法性校验并重新生成刀路，非贯通排法拒绝并撤销。
10. **导出**：排样图、裁切步骤表、下料单/领料单、A4 不干胶标签（每块零件一张），浏览器打印/另存 PDF；项目可导出/导入 JSON。读回老存档时：库为空按默认三种板接上、只有一种板保持原样、零件指向已不在库的编号清回自动挑板、旧排样结果作废重排。

## 单位与精度

- 板幅、零件长宽、修边量、锯路：毫米 **mm**，录入精度 1 位小数，单据展示取整；修边**两侧各扣一份**（可用幅面 = 板宽 − 2×trim、板高 − 2×trim）。
- 长边/短边判断按**纹理方向**分开：竖纹件录入长边沿板长边、横纹件录入宽边沿板长边，两者都不可旋转。
- 金额：分（cents）内部计算，界面/单据 ¥ 保留 2 位小数；封边长度：米 m 保留 2 位小数；利用率：百分比 1 位小数。

## 自检与验收结果

首页「运行算法自检」会在浏览器里真实执行 `src/lib/selftest.ts`（开发期另用 Node/esbuild 做过 30 个随机种子 × 100 组共 3000 组压测，零反例）：

- 100 组随机任务：guillotine 合法性、逐步切割模拟零件尺寸全部正确、纹理零旋转、锯路/修边净距、守恒（Σ排样数=总数、Σ板面积≥Σ零件面积、利用率复算）
- 30 个零件 ≤ 20 个锯切工步，且逐刀模拟后零件尺寸全部正确
- 纹理件超板幅时明确提示且不强制旋转
- 余料登记后作为小板材优先参与下一轮排样
- 300 个零件排样耗时 < 1.5s（实测约 10ms 量级）
- 手工微调的合法/塞缝布局判定准确，增量校验 < 80ms
- 板材库领域规则：同规格拒重、0/负长宽厚当场拦、修边两侧各扣且不得大于板、横纹按纹理方向比可用板幅、老存档兼容（空库接默认/悬挂编号清回自动/旧结果作废）、删板改件后输入签名变化且汇总行不残留已删板
